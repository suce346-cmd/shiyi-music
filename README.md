# shiyi音乐 — AI 音乐提示词生成器

基于 Tauri 2 + React 19 + Rust 的桌面应用，为 Suno AI 生成结构化音乐提示词。

采用**圆桌讨论流水线架构（v3）**：主持人全局统领（各模式原版指令）产出初稿 → 动态角色专业审改（先分析再按需查 CSV，输出修订片段）→ 校验员讨论轮审查（质量审查门 + 观点返回主持人）→ 主持人汇总并分发下一轮任务（≤3 轮收敛）→ 校验员按标准格式输出最终提示词包（代码硬校验兜底）。

## 开发

```bash
npm install
npm run tauri dev
```

## 构建

```bash
npm run tauri build
```

## 功能

- Mode A（歌词模式）：已有歌词 → 完整生产方案（情感 → 制作 → 主持 → 校验）
- Mode B（想法模式）：一个灵感 → 完整歌曲（情感 → 作词 → 制作 → 主持 → 校验）
- Mode C（改写模式）：原歌词 + 新主题 → 保留字数韵脚重新填词（改词 → 制作 → 主持 → 校验）
- Mode D（抖音模式）：一个灵感 → 60 秒抖音爆款片段（情感 → 作词 → 流行风格 → 制作 → 主持 → 校验）

## 角色级 API

设置面板支持为每个角色单独配置 API（模型/密钥/地址），未配置的角色共用全局 API；留空的字段继承全局。
