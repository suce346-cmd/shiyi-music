# 大型实测计划（用户指令 2026-09-09）

> 用户原话要点：单轮浅层分析不够；从产品目标出发（编曲规范性/多样性/合理性、不千篇一律、
> 歌词韵脚/规范性、hook 合理性等）；需要 5-10 轮连续实测综合分析；各种风格、各种情感、各种形式。

## 测试矩阵（40 次 API 调用）

- 四模式 × 10 提示词（风格×情感×形式三维度覆盖）
- 提示词池预先冻结（docs/qa/test-prompts.md），杜绝"看结果选输入"
- 每次记录：degraded/validation_passed/usage/终稿全文/事件流

## 产品维度评分卡（每份终稿，0-2 分，双人标准冻结在案）

| 维度 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 编曲规范性 | 违反 suno_rules 硬线 | 贴线 | 全部在区间内 |
| 编曲多样性 | 与本次测试池其他终稿 Style 相似度>70% | 部分重叠 | 独立配方 |
| 合理性 | 配器/能量自相矛盾 | 局部矛盾 | 全曲自洽 |
| 千篇一律 | 结构/金句与池内重复 | 部分套路化 | 独立结构 |
| 歌词韵脚 | 押韵混乱 | 部分押韵 | 一韵到底或有意换韵 |
| 歌词规范性 | 字数/行数违规 | 贴线 | 全部合规 |
| Hook 质量 | 无记忆点 | 有 Hook 无差异 | 记忆点+变化设计 |

## 分析产出
- 各维度分布（不是单次 pass/fail）
- 降级率与降级原因分布
- 千篇一律量化：池内 Style Prompt 两两相似度、金句重复率
- 与规则执行证据交叉：哪条规则缺席导致哪个产品缺陷
